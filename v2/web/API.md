# MVP-2.1 Local Demo API

Local-only FastAPI endpoints:

- `GET /api/health`
- `GET /api/scenarios`
- `POST/GET /api/sessions`
- `POST/GET /api/tasks`
- `GET /api/tasks/{id}/events|context|actions|progress|stream`
- `POST /api/tasks/{id}/resume`

`POST /api/tasks` accepts `session_id`, `goal`, `scenario` (`normal`, `timeout`, `repeated_final`, `long_context`) and `scenario_id` (`F001`, `F323`). All scenarios are synthetic and use a deterministic scripted driver through real Runtime/Harness components. The Completion Verifier and Progress Guard are real, but the tool sequence after an intervention is scripted rather than generated by a live model. No endpoint executes shell commands, performs live-model inference, or accesses real vehicles/ECUs.

`GET /api/health` reports `runtime_mode=deterministic_scripted_runtime` and `live_model=false` so clients can display this boundary accurately.

Context responses expose `token_count_mode` and `token_count_scope`. `exact` means a configured local Tokenizer counted a serialized payload without applying the model Chat Template; `estimated` is a UTF-8 heuristic. Values from different scopes are not divided, so `compression_ratio` remains `null` with `compression_ratio_basis=unavailable_mixed_scope`.
